# local-51 验证记录

版本：1.4.3-local-51 / 140351。设备：Air6，使用 MuMu 检查，只登录和读取状态。

## 修复内容

1. 概览请求失败时，其他并行请求可能仍在执行，旧响应可能混入下一次操作。改为等已启动的请求完成后再释放队列；正常情况下仍先展示概览。
2. 短信设置的周期刷新补齐存储位置和容量，共用同一次短信读取。
3. 定时回调稍晚时，原逻辑会误跳过下一轮。改为只有请求自身耗时达到周期才跳过重叠轮次。

这三类问题均有修复前失败、修复后通过的回归用例。
