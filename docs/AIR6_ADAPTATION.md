# Air6 / OpenWrt 适配（local-52）

面向 SoftBank Air6 的 LuCI cmodem 接口，保留独立的烽火协议。验证设备使用 OpenWrt SNAPSHOT / Linux 6.18.55；其他固件的接口和权限可能不同。

## 登录和刷新

连接设备网络后，在登录配置中填写管理地址（例如 `192.168.1.1`）、账号（通常为 `root`）和管理密码。首次成功登录后可保存配置并自动登录；认证失败时不会循环提交密码。

前台全局状态按自动刷新设置的 3/5/8 秒调度，覆盖概览、小区、控制、短信、任务、回退、Wi-Fi、WAN、DHCP 和 OTA 状态。实时网速独立按 1 秒采样；后台暂停，无操作不降频。请求耗时超过周期时不会堆积重叠请求，因此网络慢时数据完成时间可能延后。正在编辑的草稿不会被刷新覆盖。短信自动刷新默认开启，关闭后不跟随周期轮询。

## 读数口径

| 项目 | 数据和计算方式 |
| --- | --- |
| CPU | 路由器 Linux `/proc/stat` 两次采样的差值，空闲包括 idle 与 iowait；不是模拟器或手机 CPU |
| 内存实际占用 | `(total - available) / total`；没有有效 available 时回退到 free。这与将缓存计入已用内存的页面可能不同 |
| 温度 | 优先读取 CPU thermal zone 的最大温度，回退到 SoC / thermal_zone0 |
| 信号质量 | 与 Web 首页一致的服务小区参数；保留有效的 0 值，缺失值不伪装为 0 |
| 流量 | 优先 `traffic_status`，回退 `traffic_total`；十进制 GB（1 GB = 1,000,000,000 字节） |

## 功能范围

- 概览、蜂窝信号、载波和邻区、实时网速、累计/每日流量、设备版本与资源信息。
- 网络模式、频段、单小区和多小区锁定，以及解除锁定。
- Wi-Fi 名称、密码、启停和隐藏；保留未修改配置。
- 短信会话、发送、复制、删除、已读及转发/存储设置。
- 定时任务的创建、编辑、启停和删除；每天、每周与自定义 Cron。
- 锁频/小区自动回退的开关和断网超时，独立于定时任务入口。
- CFUN、USB、射频功率、IMEI、AT、重启等设备接口，具体能力以固件返回为准。
- WAN 状态与 DHCP/DHCPv6 租约；租约不等于设备当前在线。
- 固件 OTA 状态、检查、版本选择、下载和升级入口；只有确有新固件时显示“可用更新”。

完整流量策略、历史信号曲线，以及 OpenWrt VPN/防火墙管理不在本版范围内。

## 验证边界

Node 测试覆盖接口映射、错误处理、刷新调度、编辑草稿和模拟写入。Android 构建、单元测试与 lint 通过；MuMu 验证了真实设备只读数据和部分页面行为。

未为测试向真实路由器发送/删除短信、保存任务或回退设置、修改射频/网络、下载/升级固件。模拟写入测试不等于真实设备写入验收。详情见 [local-51](VERIFICATION-local-51.md) 和 [local-52](VERIFICATION-local-52.md)。这两份记录中的本机日志和截图未随源码发布。
